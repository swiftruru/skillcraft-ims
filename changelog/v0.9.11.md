## 跨回合實體記憶（Cross-turn Entity Memory）

### 改善

- **代詞自動解析**：對話中使用「他」「她」「那個供應商」「同樣的商品」等指代詞時，系統自動從本次 session 歷史（summary cache + 最近 5 則訊息的已識別實體）找出對應實體，無需使用者重複說明

  觸發邏輯：
  - 明確提及實體名稱 → 直接 LIKE 解析，不觸發
  - 代詞 + 實體解析全部失配 + 有 session 歷史 → 從歷史補充實體（純 DB 查詢，零 API 消耗）
  - 第一則訊息使用代詞（無歷史） → graceful 降級為通用統計，不 crash
