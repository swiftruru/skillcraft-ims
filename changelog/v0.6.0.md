### 新功能

- **自動更新**：透過 GitHub Releases 自動偵測並安裝新版本；App 啟動 30 秒後背景靜默檢查，有更新時在設定頁顯示版本號與下載進度條，下載完成後可一鍵安裝並重啟
- **可自訂 G+key 快捷鍵**：所有導覽快捷鍵（G+H/P/B/S/R/,…）現可在設定頁逐一修改，Sidebar hover 時顯示對應快捷鍵提示，支援「恢復預設」
- **頂部導航進度條（NavProgressBar）**：任何資料請求進行中時，頁面頂部顯示 2px 寬的藍色進度條，優雅呈現載入狀態
- **一鍵複製（CopyButton）**：商品 SKU、訂單號、客戶/供應商聯絡電話與 Email 欄位右側新增複製 icon，點擊後切換為綠色勾勾確認，1.2 秒後自動復原
- **懸停快速預覽卡（Hover Preview Card）**：採購/銷售列表的供應商/客戶名稱 hover 300ms 後顯示聯絡資訊卡片（姓名、電話、Email）
- **分類自訂顏色（Category Color Map）**：商品分類 Badge 依分類名稱 hash 自動對應 6 色（藍/紫/青/綠/橙/玫瑰），Dashboard 庫存分佈圖同步套用
- **批次匯出選取列（Export Selected Rows CSV）**：多選商品/採購/銷售後，浮動操作列新增「匯出選取」按鈕，純前端生成 CSV，加入 BOM 確保 Excel 正確顯示中文
- **DataTable 鍵盤導航**：表格支援 ↑↓ Arrow 移動選中列，Enter 開啟詳情，Home/End 跳到首末列，聚焦列顯示 ring 高亮
- **DataTable 密度切換**：三段密度（緊密／標準／寬鬆）獨立儲存於 localStorage，各頁面設定互不影響
- **搜尋框最近搜尋記錄**：搜尋框聚焦且無輸入時顯示最近 8 筆搜尋記錄下拉選單，可單筆刪除或清除全部
- **成功操作動畫回饋（Flash）**：新增/更新商品、客戶、供應商後，對應列短暫閃現綠色背景動畫（500ms）
- **Dashboard KPI 數值 Count-Up 動畫**：KPI 卡片數值以 ease-out 曲線從 0 動畫到目標值（600ms），每次資料更新自動重播
- **訂單快速備註（Quick Note Popover）**：採購/銷售列表 Row Actions 新增 MessageSquare 按鈕，inline Popover 快速新增/編輯備註，已有備註時 icon 顯示填充樣式
- **SKU 快速掃描列（SKU Quick-Add Bar）**：採購/銷售表單明細表格上方新增 SKU 輸入列，精確比對後自動 append 品項，支援條碼掃描器
- **Tab 鍵自動新增明細列**：表單最後一行最後一個欄位按 Tab，自動新增新列並移動焦點
- **頁面資料摘要列（Page Summary Strip）**：表格上方顯示即時統計（商品頁：共 N 項・N 項低庫存・庫存總值；採購/銷售頁：共 N 筆・N 筆待處理・總金額）
- **日期區間快選按鈕（Date Range Presets）**：採購/銷售頁日期篩選旁新增「今天／本週／本月／上月／近90天」快選 chip，再次點擊清除篩選
- **點擊狀態快速篩選（Click-to-Filter Badges）**：採購/銷售列表的狀態 badge 可直接點擊套用對應狀態篩選，toggle 行為；商品頁分類 badge 點擊同理
- **可互動 Summary Chips**：商品頁「N 項低庫存」、採購/銷售頁「N 筆待處理」、帳款頁「N 筆逾期」均為可點擊篩選 chip，active 狀態顯示 ring 邊框
- **庫存盤點 N 鍵快速新增**：StockTake 頁面現在也支援 N 鍵快速建立盤點單

### 無障礙（Accessibility / WCAG AA）

- **aria-current="page"** 加入 Sidebar 現有頁面導覽項目
- **useFocusReturn hook**：Dialog 關閉後自動將焦點歸還觸發元素
- **DataTable aria-sort / role="grid"**：表格欄標題支援 `aria-sort`，完整 `role="grid/row/gridcell/columnheader"` 語義
- **aria-busy** 加入資料載入中的表格容器
- **系統深淺色主題即時同步**：`nativeTheme.on('updated')` 即時推送至 renderer，切換系統主題時 app 同步更新 DOM class
- **Status badge sr-only 文字**：所有狀態/付款 badge 加入 `<span className="sr-only">` 前綴，供螢幕閱讀器播報「狀態：」「付款狀態：」
- **CreatableSelect 完整 ARIA combobox**：`role="combobox"、aria-expanded、aria-activedescendant、role="listbox/option"`，完整鍵盤可操作
- **Context Menu 鍵盤開啟**：DataTable 支援 Shift+F10 / ContextMenu 鍵開啟右鍵選單，選單加入 `role="menu/menuitem"`
- **路由切換後焦點移至 main 內容**：每次頁面切換後自動 focus `#main-content`，讓鍵盤/螢幕閱讀器使用者不需重新定位
- **prefers-contrast CSS 強化**：`@media (prefers-contrast: more)` 加強 border 與文字對比
- **rem 字型基礎**：`html { font-size: 100% }` 尊重使用者瀏覽器字型偏好設定
- **prefers-reduced-motion**：停用 CSS 動畫（flash、fade-in、nav-progress）以支援動態敏感使用者
