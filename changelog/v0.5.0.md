## 新功能

### 帳款管理（應收 / 應付帳款）

- 新增獨立「帳款管理」頁面：統一顯示應收（銷售）與應付（採購）未付款項
- 採購單與銷售單表單新增「帳期」欄位（30 / 45 / 60 天），送出後自動計算 `payment_due_date`
- 帳款列表支援應收 / 應付切換、逾期篩選與關鍵字搜尋
- **帳齡分析**：將未付款項依逾期天數分為「未到期 / 逾期 1–30 天 / 逾期 31–60 天 / 逾期 60 天以上」四個色段卡片，金額加總一覽無遺
- **即將到期提醒（7 天內）**：帳款頁顯示琥珀色「即將到期」badge；Dashboard 新增「即將到期」警示卡片
- **標記付款**：採購單與銷售單詳情 Dialog 底部新增「標記已付款」按鈕（`received` / `completed` 且 `unpaid` 才顯示），含二次確認
- 側邊欄顯示「帳款管理」逾期數量徽章（紅色）

### 信用額度管理

- 供應商與客戶新增 `credit_limit` 欄位（0 = 不限制）
- 客戶詳情 Dialog 顯示信用額度進度條（已用 / 上限，顏色隨使用率變化）
- 建立銷售單時若客戶未付款金額超出信用額度，彈出黃色警告卡片（不阻擋送出，僅提示）

### 商品圖片

- 商品表格與詳情 Dialog 支援縮圖顯示
- 商品表單新增圖片上傳（拖放 / 點擊選擇），最大 10 MB，自動縮放存入 BLOB
- 詳情 Dialog 支援點擊放大預覽

### AVCO 加權平均成本

- 每筆採購入庫後自動更新 `avco_cost`（Weighted Average Cost）
- 銷售出貨毛利計算改以 AVCO 成本為基礎，更準確反映實際獲利

### 部分退貨（Partial Return）

- 銷售單新增 `partial_return` 狀態，支援只退部分品項
- 銷售單狀態工作流程加入部分退貨分支

### AI 需求預測（需 Claude API Key）

- 設定頁面新增 Claude API Key 輸入
- `ai:forecast` IPC 讀取近 30 天銷售資料，呼叫 Claude Haiku 分析需求趨勢
- 回傳整體摘要 + 各商品建議補貨量與原因

### 報表強化

- **ABC 分析**：依銷售額將商品分為 A / B / C 三級
- **損益表（P&L）**：指定期間的收入、成本、毛利一覽
- **批次調價**：商品頁可多選後統一設定售價或進價

## 問題修復

- 修正 `payment_due_date` 為 null 時 Dashboard 逾期卡片報錯
- 修正 Migration 014 / 015 / 016 未註冊導致 `credit_limit`、`partial_return` 欄位不存在
- 修正通知中心從未顯示低庫存通知（`checkLowStockNotification` 現在同時寫入 `app_notifications` 資料表）

## UX 改善

- Header 低庫存警告徽章改為可點擊連結，點擊直接跳至商品頁並套用低庫存篩選
- Demo 資料產生（設定頁面）大幅更新：
  - 供應商 / 客戶含信用額度（40% / 30% 機率）
  - 採購單 / 銷售單含帳款資訊（`payment_status`、`payment_due_date`）
  - 保證生成逾期（3–5 筆銷售、2–3 筆採購）與即將到期（2–3 筆銷售、1–2 筆採購、1 筆今日到期）情境訂單
  - 生成 2–3 筆已完成盤點 + 1 筆進行中盤點，讓庫存盤點頁面立即可用
  - 銷售單狀態分佈加入 `partial_return`（5%）
