## 修復 macOS 自動更新安裝失敗（根本解決方案）

### 修復

- **macOS 更新流程改為導向下載頁面**：先前版本嘗試透過 Squirrel.Mac（ShipIt）直接安裝更新，但因 CI 建置的 app bundle 含有 Electron 框架的原始簽名，在被 electron-builder 修改資源後形成無效簽名，ShipIt 驗證時一律報錯「code has no resources but signature indicates they must be present」

  根本原因：ShipIt 的程式碼簽名驗證無法透過 API 關閉，`identity: null` 只阻止了 electron-builder 主動簽名，無法移除 Electron 框架二進位已有的簽名殘留。

  解決方式：macOS 上停用自動下載與 ShipIt 安裝流程；當偵測到新版本時，設定頁面改顯示「前往下載頁面」按鈕，點擊後開啟 GitHub Releases 頁面，讓使用者手動下載 DMG 安裝（Windows 更新流程不受影響）。
