### 新功能

- **AI 需求預測獨立頁面**：側邊欄新增「AI 需求預測」入口（Brain icon），功能從 Dashboard widget 獨立為完整頁面；分析結果以表格完整呈現，含預估售完天數（< 7 天橘色警示）與各商品補貨建議原因
- **AI 結果持久化**：預測結果存入本地 SQLite（`ai_forecasts` 資料表），重啟 App 或再次進入頁面仍保留上次結果，不需重複呼叫 API
- **動態版本號**：右下角狀態列版本號改由 `package.json` 自動注入，不再寫死

### 改善

- **AI JSON 解析強化**：以 `indexOf` / `lastIndexOf` 取代 Regex 提取 JSON，避免截斷邊界誤判；`max_tokens` 提高至 4096，`LIMIT` 調整為 10 筆，降低回應截斷機率
- **AI SQL 修正**：移除 `WHERE` 子句對聚合別名的錯誤引用（`SUM()` misuse），改以 `HAVING` 正確過濾
- **自動更新 IPC 修正**：dev 模式下 `updater:checkForUpdates` handler 現在總是被註冊，不再因 `is.dev` 早期返回而拋出「no handler」錯誤；dev 環境點擊「檢查更新」會回傳「已是最新版本」

### 無障礙（WCAG 2.1 / 2.2）

系統性實作 99 項 WCAG 無障礙規則，涵蓋：

- **表格語意完整**：`role="grid"`、`aria-sort`、`aria-rowcount`、`scope="col"`、`aria-label`、`<caption>` 等
- **鍵盤導航**：DataTable 支援 ↑↓ / Enter / Home / End 鍵盤操作；拖曳排序提供 ▲▼ 鍵盤替代按鈕
- **表單無障礙**：`aria-invalid` + `aria-describedby` 錯誤關聯；提交失敗後顯示錯誤摘要區塊（`role="alert"`）
- **焦點管理**：Dialog 開啟後 focus 移至第一個輸入欄位；關閉後 focus 歸還觸發按鈕；Skip Navigation 連結
- **螢幕閱讀器**：`aria-live` 公告區（polite / assertive）；`role="status"` 載入指示；sidebar badge 增減自動播報
- **視覺與運動**：`prefers-reduced-motion` 停用自訂動畫；`prefers-contrast: more` 提高對比；觸控目標最小 24px
- **系統整合**：`nativeTheme` 跟隨系統深淺色切換；`<html lang>` 隨語言切換動態更新；圖表補 `aria-label` 替代說明
- **Combobox 語意**：`CreatableSelect` 補完 ARIA Combobox 屬性（`role="combobox"`、`aria-expanded`、`aria-autocomplete`）及鍵盤導航
