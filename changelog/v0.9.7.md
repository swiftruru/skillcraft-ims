## 語意實體匹配（Semantic Entity Fallback）

### 改善

- **縮寫 / 別名 / 拼字相似實體識別**：LIKE 全部失配時，自動啟動語意消歧義 fallback，以 Haiku 比對資料庫中的實際商品、客戶、供應商清單，找出最可能對應的實體（例如「台電」→「台灣電子股份有限公司」），並注入精確 SQL 過濾條件，回答更針對性、不再退化為全表摘要

- **Alias 快取持久化**：成功對應後將 alias → entity 映射寫入新的 `entity_aliases` SQLite 表；下次相同縮寫直接查表，不再呼叫 API，兼顧精準度與 token 用量

  觸發邏輯：
  - 問題含實體詞且 LIKE 命中 → 不觸發（零額外消耗）
  - 問題含實體詞但 LIKE 全失配，alias 有快取 → 查表命中（零 API）
  - 問題含實體詞但 LIKE 全失配，alias 無快取 → Haiku 消歧義 +1 次（結果存快取）
  - 問題只含通用概念（如「庫存概況」）→ 不觸發（無候選詞元）
