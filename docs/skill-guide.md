# Claude Code Skills 使用指南

SkillCraft IMS 內建 5 個 Claude Code Skills，可直接對 SQLite 資料庫執行查詢，
產生 AI 驅動的分析報告與操作指引。

## 前置需求

1. 安裝 [Claude Code](https://claude.ai/claude-code)
2. 在 SkillCraft IMS 專案目錄中啟動 Claude Code：
   ```bash
   cd /path/to/skillcraft-ims
   claude
   ```
3. 確認 SkillCraft IMS 已執行過一次（資料庫已初始化）

---

## 可用 Skills

### `/inventory-report` — 庫存分析報告

**功能**：查詢所有商品的庫存狀況，產生包含類別分佈、利潤分析、
低庫存警示的完整報告，並提供具體建議行動。

**輸出範例**：
```markdown
# 庫存分析報告
日期：2026-03-07

## 執行摘要
庫存健康狀況良好，共 15 種商品，總庫存值 NT$ 482,000。
電子產品類別佔最大比例（68%），有 2 項商品低於補貨點需立即補貨。

## 類別分佈
| 類別 | 商品數 | 庫存值 | 平均毛利率 |
...
```

**使用方式**：
```
/inventory-report
```

---

### `/reorder-alert` — 低庫存警示與補貨建議

**功能**：掃描所有低於補貨點的商品，根據近 90 天銷售量計算
剩餘天數與建議補貨量，提供優先序排列的補貨清單。

**功能特色**：
- CRITICAL / WARNING 優先序分類
- EOQ 簡易模型計算建議補貨量
- 可輸出按供應商分組的草稿採購單

**使用方式**：
```
/reorder-alert
```

---

### `/sales-analysis` — 銷售趨勢分析

**功能**：多維度銷售分析，涵蓋趨勢、產品績效矩陣、客戶行為，
並與前期比較。

**功能特色**：
- 期間可自訂（預設 30 天）
- 產品績效矩陣（明星/現金牛/問號/瘦狗）
- MoM 同比增減分析

**使用方式**：
```
/sales-analysis          # 最近 30 天
/sales-analysis 90       # 最近 90 天
```

---

### `/import-data` — 資料批次匯入

**功能**：引導 CSV 資料匯入流程，自動偵測欄位、映射到資料庫，
使用事務確保資料一致性。

**支援類型**：商品、供應商、客戶

**功能特色**：
- 支援中英文欄位名稱自動辨識
- UPSERT 模式（可選擇更新或跳過重複項）
- 自動建議備份

**使用方式**：
```
/import-data
```

---

### `/sync-sheets` — Google Sheets 同步管理

**功能**：Google Sheets 同步的完整管理工具，包含觸發、監控、診斷。

**功能特色**：
- 查看近期 20 筆同步日誌
- 常見錯誤自動診斷與解決方案
- 首次設定完整引導流程

**使用方式**：
```
/sync-sheets
```

## Skill 設計原則

這些 Skills 的設計遵循以下原則，區別於一般 AI 提示詞：

1. **真實資料查詢**：直接對 live SQLite 資料庫執行 SQL 查詢，非靜態示範
2. **行動導向**：每個 Skill 不只分析，還提供具體的下一步行動
3. **安全操作**：寫入操作前會確認，批次操作會建議備份
4. **離線優先**：即使 Google Sheets 未設定，Skill 仍可查詢本機資料庫運作
